# Public surface guardrail

This public repository is no longer the canonical target for new proprietary/commercial-core development.

## Rule

- Keep public documentation, evidence, demos, intentionally open interfaces/schemas, and reviewed exports here.
- Do not start new closed-core work here.
- If a task touches commercial runtime internals, entitlement/revocation, pricing/metering, private packaging, proprietary routing/orchestration, unreleased implementation work, internal acceptance assets, or other copy-sensitive value, stop and route the task to the authorized private canonical WebAI Bridge repository.
- Public export must remain reviewed and allowlist-driven.

Historical public source remains valid public history. This guardrail protects future proprietary delta; it does not claim retroactive secrecy.
